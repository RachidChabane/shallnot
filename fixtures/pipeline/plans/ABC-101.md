# ABC-101: Export an invoice as PDF

## Context

Support receives monthly requests for PDF copies of invoices. The export is
rendered by the service and triggered from the web client.

## Acceptance criteria

- **ABC-101.AC1~1**: WHEN the client requests an invoice export THE SYSTEM
  SHALL return a PDF named after the invoice number.
- **ABC-101.AC2~1**: WHEN a customer clicks "Export" THE SYSTEM SHALL start
  the download without leaving the page.
- **ABC-101.AC3~1**: THE exported PDF SHALL match the brand guidelines.
  - Non-testable: reviewed by the brand team on each template change; no
    automated check covers visual identity.
